# AI 활용 및 데이터 출처

## AI 활용 범위

- 사용자 역량과 채용공고의 실제 업무가 연결되는 이유를 설명
- AI는 매칭 점수 자체를 결정하거나 합격 가능성을 예측하지 않음

## 개인정보 원칙

- 실명, 이메일, 전화번호, 주소, 생년월일, 주민등록번호를 AI 프롬프트에 입력하지 않음
- 이력서 원본을 외부 AI API로 직접 전송하지 않음
- 사용자는 구조화된 프로필 폼에 실명·연락처를 제외한 경력 정보만 직접 입력

## 검증 원칙

- AI가 생성한 추천 이유는 팀이 발표 전에 검토
- 매칭 점수는 코드 기반 참고 지표이며 합격 확률이 아님

## 데이터 출처

- 현재 `data/jobs.ts`의 공고는 UI와 매칭 로직 검증을 위한 가상 샘플 데이터
- 실제 발표 및 서비스에서는 각 공고의 원문 URL, 수집일과 제공 기관을 함께 표기
- 통계나 정책 정보는 원 데이터의 기관명, 문서명, 기준일과 URL을 발표자료에 표기
